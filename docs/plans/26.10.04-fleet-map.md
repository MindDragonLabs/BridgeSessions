## Build hosts

| host | role | how it is driven |
|---|---|---|
| fecv3 | linux + windows cross | native; `x86_64-w64-mingw32-g++` present |
| jeffersons-mac-mini | macOS | `bs shell macmini`; mesh seed `macmini <tailnet-ip>` |

mac mini specifics, verified live:

- `Darwin ... arm64`, macOS 27.0.1, 16 GB RAM, Apple clang 21.
- **cmake and ninja are NOT on the non-login PATH.** They live at
  `/opt/homebrew/bin/{cmake,ninja}` and appear only in `/bin/zsh -lic`. A plain
  `bridgesessions shell` one-shot gets a non-login shell, so a remote build must
  export `PATH=/opt/homebrew/bin:$PATH` itself.
- The `mac` SSH alias points at **MacBook, not mac mini** (`~/.ssh/config`,
  repointed 2026-08-19). Use `bs shell macmini` or the explicit
  `jefferson@<tailnet-ip>`; the `mac` alias silently reaches the wrong host.
- A macOS build outlives one shell call. `nohup ... &` children are killed when
  the BridgeSessions session tears down, which truncated the first attempts
  mid-configure. Launch it through `launchctl` instead — a plist at
  `/tmp/bs-build.plist`, label `bs-build-261004`, logging to `/tmp/macos5.log`.
- Deleting `build/macos-arm64` forces OpenSSL to rebuild from source and that
  dominates build time. Keep the directory.
